# T3 Code 日本語化フォーク（local-ja）

これは、T3 Code（本家: [pingdotgg/t3code](https://github.com/pingdotgg/t3code)）の日本語化フォーク [nagisora/t3code](https://github.com/nagisora/t3code) です。

- **ベース**: 安定版タグ **v0.1.9**（main ではありません）
- **ブランチ**: `local-ja`
- **目的**: T3 Code の UI を日本語で使うためのフォークです。本家への還元（PR）は想定していません。

## コミット構成

ベース（v0.1.9）の上に、性質の違う2層のパッチが積まれています。

### 1. `[official-ja-settings]` コミット群 — 公式の設定画面 i18n の先行取り込み

本家では言語切り替え機能（PR #31313）と日本語翻訳（PR #33164）が 2026-11-12 に main へマージされましたが、安定版 v0.1.9 のタグ付け（2026-11-11）より後だったため、安定版には入っていません。このフォークではその2つの公式 PR を v0.1.9 へバックポートしています。

| コミット                           | 内容                                                                           |
| ---------------------------------- | ------------------------------------------------------------------------------ |
| `[official-ja-settings]` #31313    | 言語切り替えの土台（GT 方式、`apps/web/src/i18n/`、設定画面の言語ピッカー）    |
| `[official-ja-settings]` #33164    | 日本語翻訳そのもの（`apps/web/src/i18n/translations/ja.json`、設定画面72項目） |
| `[official-ja-settings]` pnpm-lock | 上記に伴う依存関係のロックファイル解決分                                       |

適用時の手当て（最小限）:

- #31313 は `appInit.tsx` と `SettingsSidebarNav.tsx` で v0.1.9 と文脈がずれたため、同じ変更を手で適用しました。それ以外は公式差分どおりです。
- #33164 は兄弟ロケール PR に積み重なった PR だったため、`ja.json` は公式ファイルとバイト単位で同一のものを使い、残り3ファイル（`gt.config.json`、`locales.ts`、`settingsSearch.ts`）は同じ内容を手で適用しました。

**将来の安定版に公式で言語切り替え＋日本語が入ったら、この層は全部外します**（外し方は「アップデート運用」参照）。

なお、この翻訳の範囲は**設定画面のみ**です。設定画面で言語を「日本語」に切り替えると設定画面が日本語になります。UI 本体は次の層が担当します。

### 2. `[local-ja]` コミット — UI 本体の日本語化

UI 本体の文字列は本家ではまだ言語ファイル化されていないため、このフォークではコンポーネント内の英語文字列を直接日本語に置き換えています（ハードコード置換）。対象は主要画面の見える範囲です（13ファイル・約85箇所）:

- サイドバー／スレッド一覧: 「新規スレッド」ボタン、セクション見出し（ピン留め／アクティブ／作業中）、プロジェクト検索、スレッド右クリックメニュー（新規スレッド、パスをコピー、プロジェクト設定 など）
- スレッドのアクションメニュー全般: ピン留め、名前を変更、スレッドをアーカイブ、削除、コピー、スヌーズ、完了にする など
- チャット画面: 入力欄のプレースホルダ（「何でも聞いてください…」）
- 右パネルタブ: ブラウザ／ターミナル／ファイル／差分／プルリクエスト／デバイス／サイドチャット、「パネルを開く」
- 差分画面の見出し: 「変更」「未コミット」
- コマンドパレットのプレースホルダ、空状態の文言（「アクティブなスレッドなし」「続けるスレッドを選んでください」）

全画面の網羅はしていません。新しい画面で英語が残っていたら、その都度この層に置換を足す運用です。

## セットアップ

前提: Git が使えること。Node は `vp` が指定バージョン（Node 26）を用意するので、別途インストール不要です。

### 1. vp（Vite Plus）のインストール

Windows（PowerShell）:

```powershell
irm https://vite.plus/ps1 | iex
```

macOS / Linux:

```sh
curl -fsSL https://vite.plus | bash
```

### 2. clone とブランチのチェックアウト

```sh
git clone https://github.com/nagisora/t3code.git
cd t3code
git checkout local-ja
```

### 3. 依存関係のインストール

```sh
vp i
```

### 4. 起動

Web 版（サーバー＋Web UI）:

```sh
vp run dev
```

デスクトップ版（Electron）:

```sh
vp run dev:desktop
```

Web 版は起動時に dev ランナーが**ペアリング URL** を表示します。新しいブラウザでは素の URL だけでは認証されないので、表示されたペアリング URL を開いてください。

### 5. 設定画面を日本語にする

設定（Settings）→ 一般（General）→ 言語（Language）で「日本語」を選ぶと、設定画面が日本語表示になります（公式翻訳の範囲）。

### 6. エージェント CLI（別途必要）

T3 Code 自体はモデルを持たず、既存のエージェント CLI を束ねる道具です。使うエージェント（例: Claude Code）のインストールとログインが別途必要です。

```sh
# 例: Claude Code を入れてログインする（各エージェントの公式手順に従う）
claude auth login
```

エージェントが1つも入っていないと、スレッドを作っても実行できません。

## アップデート運用

リモート構成は `origin` = このフォーク（nagisora/t3code）、`upstream` = 本家（pingdotgg/t3code）です。本家には push しません。

### 新しい安定版を取り込む

```sh
git fetch upstream --tags
git checkout local-ja
git rebase v0.2.0        # 例: 新しい安定版タグに載せ替える
vp i                     # 依存関係を更新
```

競合したら、まず `[local-ja]` 層（文字列置換）側を新しいコードに合わせて直します。文字列置換は行単位の小さい差分なので、多くの場合は対象文字列を探し直すだけで済みます。

### `[official-ja-settings]` 層の外し方

取り込み先の安定版に、公式の言語切り替えと日本語が含まれているかを確認します:

- `apps/web/src/i18n/translations/ja.json` が存在する
- `apps/web/gt.config.json` の `locales` に `"ja"` がある

両方あれば公式入り済みなので、rebase 中に対象コミットを drop します:

```sh
git rebase -i v0.2.0
# [official-ja-settings] の3コミット（#31313 / #33164 / pnpm-lock）を drop とマークする
```

drop したあと `vp i` で依存関係をそろえれば、設定画面の日本語は公式のものに切り替わります。

## 注意点

- **このフォークは公開リポジトリです。** 認証情報や個人情報などの秘密情報はコミットしないでください。
- 本家の CONTRIBUTING は「チーム外からの新機能 PR は受け付けない」方針です。このフォークの変更を本家へ PR する前提にはしていません。
